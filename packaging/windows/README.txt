数据统计工作台 · 用户指南
版本 v1.1.0  |  Windows 10 / 11 64 位
下载页 https://github.com/lirunwen/data-stats-workbench/releases/latest
======================================================================

一、系统要求
  操作系统：Windows 10 / 11，64 位
  磁盘空间：约 60 MB（程序），另加数据占用
  浏览器：Edge / Chrome / Firefox 任一现代浏览器
  不需要安装 Python、Office、Node.js、数据库或任何运行库
  不需要联网，目标电脑可以完全断网

二、下载与校验
  1. 打开上面的下载页。
  2. 在 Assets 中下载 DataStatsWorkbench-Windows-x64-v1.1.0.zip。
  3. 可选校验（PowerShell）：
       Get-FileHash .\DataStatsWorkbench-Windows-x64-v1.1.0.zip -Algorithm SHA256
     与发布页说明中的 SHA-256 比对。
  注意：不要在压缩包内直接双击运行，请先完整解压。

三、安装与启动
  方式 A 便携运行（推荐先试）
    1. 右键 ZIP -> 全部解压缩，解压到任意目录，例如 D:\DataStatsWorkbench
    2. 进入文件夹，双击 Start-DataStats.vbs
    3. 等待 2-5 秒，浏览器自动打开工作台
    4. 首次启动会自动创建 data 数据目录
    移动位置时请整个文件夹一起移动。

  方式 B 安装到本机
    1. 解压 ZIP
    2. 双击 Install-DataStats.cmd（不需要管理员权限）
    3. 程序复制到 %LOCALAPPDATA%\DataStatsWorkbench，
       并在桌面与开始菜单创建「数据统计工作台」快捷方式
    4. 之后从桌面或开始菜单启动

  启动之后
    · 只监听 127.0.0.1，同一局域网的其他电脑无法访问
    · 默认端口 8765，被占用时自动使用 8766、8767 ……
    · 浏览器没自动打开时，按窗口提示的 http://127.0.0.1:端口 手动访问
    · 关闭浏览器不会停止后台服务；彻底退出请用
      「设置与数据安全 → 退出工作台」

四、首次使用：五分钟上手
  1. 打开左侧「批量导入」
  2. 把 Excel / CSV 拖进虚线区域，或点「选择文件」
  3. 核对右侧字段映射：业务日期、金额、收支类型为必填
  4. 点「校验数据」，查看异常 / 重复 / 提示
  5. 确认后点「确认导入」，异常行不会写入
  6. 回到「经营总览」查看收入、支出、净额与趋势
  想先看效果：在总览空状态页点「载入演示数据」，可随时一键清除。

五、使用说明
  5.1 支持的格式
    Excel     .xlsx  .xlsm  .xls（支持多工作表、隐藏工作表）
    文本表格  .csv  .tsv  .txt（自动识别 UTF-8 / GBK / UTF-16）
    邮件      .msg  .oft（自动展开邮件附件）
              .eml（同上，并支持正文 HTML 表格）
    不支持    .xlsb、加密 Office 文件、.pst / .ost

  5.2 字段映射
    · 系统按中英文同义词自动匹配，通常可直接使用
    · 表头不在第一行：在映射页右上角「表头行」改选
    · 收入 / 支出分两列：金额列选「收入金额 / 支出金额双列」，
      系统自动拆成两笔记录
    · 整张表同收支：在「收支类型」选「整表收入 / 整表支出」
    · 多个工作表可分别勾选、分别映射
    · 相同表头下次自动套用上次映射（可在设置中关闭）

  5.3 校验与判重
    正常      字段完整，写入
    有提示    可导入但有注意事项，写入
    异常      日期 / 金额 / 收支类型无法识别，不写入
    疑似重复  按你选择的策略处理
    · 「下载校验明细」可得完整 CSV，在 Excel 修正后重新导入
    · 有单据编号：年份 + 收支 + 单据编号 + 金额 + 类别
    · 无单据编号：日期 + 收支 + 金额 + 类别 + 部门 + 往来单位 + 备注
    · 重复策略可选「跳过重复」或「更新已有记录」

  5.4 数据明细
    关键字搜索、按日期 / 收支 / 类别 / 部门 / 来源筛选、分页排序
    单条编辑删除、批量删除
    导出当前筛选结果为 Excel（含汇总页）或 CSV

  5.5 经营总览
    KPI 与上期对比、本月 / 本季 / 本年 / 全部 / 自定义期间
    近 12 个月趋势、收支构成、部门表现、数据质量
    点击类别或部门可下钻到明细

  5.6 设置与数据安全
    单位名称、重复默认策略、是否记住字段映射
    查看数据目录与占用、立即备份、清理临时上传
    字段映射管理、操作记录、版本与离线升级

六、数据、备份与迁移
  6.1 数据位置
    便携运行  ：程序目录下的 data\
    安装到本机：%LOCALAPPDATA%\DataStatsWorkbench\data
    目录结构
      data\workbench.db   主数据库（SQLite）
      data\staging\       上传暂存（24 小时自动清理）
      data\reports\       批次异常明细 CSV
      data\backup\        每日自动备份 + 手动 / 升级前备份
      data\updates\       离线升级包暂存
      data\logs\          运行日志 workbench.log

  6.2 备份
    · 自动：每天首次启动保留一份 workbench-daily-YYYYMMDD.db，保留 14 份
    · 手动：设置页「立即备份」，下载一份数据库文件
    · 建议每周复制到网盘或移动硬盘

  6.3 恢复
    1. 退出工作台
    2. 把备份文件复制为 data\workbench.db，覆盖原文件
    3. 删除同目录下的 workbench.db-wal 与 workbench.db-shm
    4. 重新启动

  6.4 换电脑
    把整个 data 文件夹复制到新电脑的对应位置即可，不需要导出再导入。

七、升级
  1. 从发布页下载升级包（.zip / .hcup）或新的完整包
  2. 设置与数据安全 → 版本与离线升级，选择升级包
  3. 本机逐文件校验 SHA-256，新版本放在独立版本目录
  4. 按提示重启生效，旧版本保留可回退
  5. 升级前会自动备份数据库，且不改动 data 目录

  从 v1.0.0 旧版本升级请注意：
  v1.1.0 改了产品标识与数据库文件名，旧升级包会被拒绝，
  请直接下载完整包，并按第八节迁移数据。

八、从 v1.0.0 旧版本迁移（必读）
  v1.1.0 把数据库文件名从 hengce.db 改为 workbench.db，旧库不会被自动识别。
  不做这一步，旧数据等于丢失。

  便携版
    1. 退出工作台
    2. 把旧目录 data\hengce.db 改名为 data\workbench.db
    3. 删除同目录的 hengce.db-wal、hengce.db-shm
    4. 用新版启动

  安装版
    1. 备份旧目录 %LOCALAPPDATA%\HengCeWorkbench\data
    2. 把整个 data 复制到 %LOCALAPPDATA%\DataStatsWorkbench\
    3. 在其中把 hengce.db 改名为 workbench.db，删掉旧的 -wal / -shm
    4. 用新版 Install-DataStats.cmd 重装并启动，确认数据在
    5. 确认无误后删除旧的 %LOCALAPPDATA%\HengCeWorkbench 与旧快捷方式

九、常见问题
  Q1 双击 Start-DataStats.vbs 没有反应
     先运行 Diagnostics.cmd 查看缺失项，再看 data\logs\workbench.log。
     最常见原因是没有完整解压，或只复制了压缩包里的部分文件。

  Q2 浏览器没有自动打开
     按启动窗口提示的 http://127.0.0.1:端口 手动访问。

  Q3 关闭浏览器后程序还在运行
     后台服务仍在监听本机端口。彻底退出：设置与数据安全 → 退出工作台。

  Q4 同事的电脑打不开我的地址
     设计如此。只监听 127.0.0.1，仅本机可访问，数据不出这台电脑。

  Q5 邮件是 .pst / .ost
     这是邮箱数据库格式，不直接解析。请在 Outlook 中另存为 .msg，
     或直接把附件拖进导入页。

  Q6 表头识别错了行
     在映射页右上角「表头行」下拉改选。跨行合并表头建议先在 Excel 整理。

  Q7 提示疑似重复，但确实有两笔相同的
     判重是保守的。用单据编号或备注区分这两笔即可正常导入。

  Q8 异常行太多
     点「下载校验明细」，在 Excel 里按行号批量修正源文件后重新导入。

  Q9 导入很慢或页面卡住
     单文件上限 80 MB、单次上传 240 MB、单表上限 50,000 行。
     超大文件请按年度或部门拆分，并另存为 .xlsx。

  Q10 导出 Excel 要等几秒
     5 万行约需 5-10 秒，属正常（写文件本身耗时）。期间请勿重复点击。

  Q11 升级后打不开
     运行 Recovery-DataStats.cmd，选择之前的版本恢复启动。数据目录不受影响。

  Q12 数据会不会上传到网上
     不会。全部在本机进程内解析，代码中没有任何外部接口调用。

  Q13 杀毒软件报警
     未签名的 .vbs / .cmd 启动脚本可能被启发式规则标记，属常见误报。
     可用 Start-DataStats-Console.cmd 从命令行启动查看具体行为。

  Q14 忘记备份，数据库坏了
     先看 data\backup\ 里的每日自动备份（保留 14 份），按 6.3 节恢复。
     启动时会做数据库完整性检查并给出提示。

十、卸载
  便携版
    1. 退出工作台
    2. 先备份 data\ 整个文件夹（如果还要这些数据）
    3. 删除整个程序文件夹
       删除前确认任务管理器里没有 pythonw.exe 在运行

  安装版
    1. 退出工作台
    2. 删除桌面与开始菜单的「数据统计工作台」快捷方式
    3. 删除 %LOCALAPPDATA%\DataStatsWorkbench 整个目录
       该目录同时含程序与数据，想保留数据请先复制出 data
    4. 完成。程序不写注册表、不装服务、不留后台进程

  卸载不会自动删除你下载到别处的备份文件。

十一、隐私与安全
  · 全程离线：无 CDN、无外部字体、无云端接口
  · 仅监听 127.0.0.1，并校验 Host 与请求来源，拒绝跨站写入
  · 不写注册表、不安装系统服务、不需要管理员权限
  · 升级包在本机逐文件校验 SHA-256，但未做数字签名，
    请只使用本项目发布页分发的包

  请像保管 Excel 台账一样保管 data 文件夹与数据库备份。
