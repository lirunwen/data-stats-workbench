# 数据统计工作台 · 用户指南

> 适用于 Windows 10 / 11（64 位）
> 当前版本：**v1.1.0**
> 下载地址：<https://github.com/lirunwen/data-stats-workbench/releases/latest>

数据统计工作台是一个**完全离线**的经营数据工具：把 Excel 台账或 Outlook 邮件拖进来，
它会自动识别表头、校验数据、合并重复项，并汇总成可读的仪表盘。所有文件只在本机解析，
不连接云端、CDN 或任何外部接口。

---

## 一、系统要求

| 项目 | 要求 |
|---|---|
| 操作系统 | Windows 10 / 11，64 位（x64） |
| 磁盘空间 | 约 60 MB（程序）+ 数据占用 |
| 内存 | 2 GB 以上 |
| 浏览器 | Edge / Chrome / Firefox 任意现代浏览器 |
| 其他 | **不需要**安装 Python、Office、Node.js、数据库或任何运行库 |
| 网络 | **不需要联网**，目标电脑可以完全断网 |

> 程序内置 Python 3.12 运行时与全部依赖，解压即用。

## 二、下载

1. 打开 <https://github.com/lirunwen/data-stats-workbench/releases/latest>
2. 在 **Assets** 中下载 `DataStatsWorkbench-Windows-x64-v1.1.0.zip`（约 12–15 MB）
3. 校验（可选，但建议）：在 PowerShell 中执行

   ```powershell
   Get-FileHash .\DataStatsWorkbench-Windows-x64-v1.1.0.zip -Algorithm SHA256
   ```

   将结果与 Release 说明中的 SHA-256 比对，一致才继续。

> 请不要在压缩包内直接双击运行。Windows 会把 ZIP 当文件夹打开，程序会因为找不到运行时文件而报错。

## 三、安装与启动

有两种方式，**便携运行**适合试用或放在 U 盘里；**安装到本机**适合长期使用。

### 方式 A：便携运行（推荐先试）

1. 右键 ZIP → **全部解压缩**，解压到任意目录，例如 `D:\DataStatsWorkbench`。
2. 进入解压后的文件夹，双击 **`Start-DataStats.vbs`**。
3. 稍等 2–5 秒，浏览器会自动打开工作台页面。
4. 首次启动会在程序目录下自动创建 `data\` 数据目录。

> 移动位置时请**整个文件夹一起移动**，不要只复制其中一部分。

### 方式 B：安装到本机

1. 解压 ZIP。
2. 双击 **`Install-DataStats.cmd`**（不需要管理员权限）。
3. 程序会复制到 `%LOCALAPPDATA%\DataStatsWorkbench`，并在**桌面**和**开始菜单**创建「数据统计工作台」快捷方式。
4. 之后从桌面或开始菜单启动即可。

安装版的数据保存在 `%LOCALAPPDATA%\DataStatsWorkbench\data`，升级程序不会动它。

### 启动后是什么样

- 程序只监听 `127.0.0.1`，同一局域网的其他电脑**无法访问**。
- 默认端口 `8765`；若被占用会自动使用 8766、8767……
- 浏览器没有自动打开时，按窗口里提示的 `http://127.0.0.1:端口` 手动访问。
- 关闭浏览器标签页**不会**停止后台服务；要彻底退出请用「设置与数据安全 → 退出工作台」。

## 四、首次使用：五分钟上手

1. 打开左侧「**批量导入**」。
2. 把 Excel / CSV 文件拖进虚线区域（或点「选择文件」）。
3. 系统自动识别表头与字段，核对右侧「字段映射」：
   - **业务日期**、**金额**、**收支类型**是必填三项；
   - 红色星号表示必填，其余可留空。
4. 点「**校验数据**」，查看异常 / 重复 / 提示三类结果。
5. 确认无误后点「**确认导入**」。异常行不会写入，重复行可选择跳过或更新。
6. 回到「经营总览」即可看到收入、支出、净额与趋势图。

> 想先看效果？在「经营总览」空状态页点「载入演示数据」，会生成一批带「演示」标记的流水，可随时一键清除。

## 五、使用说明

### 5.1 支持的文件格式

| 类型 | 扩展名 | 说明 |
|---|---|---|
| Excel | `.xlsx` `.xlsm` `.xls` | 多工作表、隐藏工作表均可识别 |
| 文本表格 | `.csv` `.tsv` `.txt` | 自动识别 UTF-8 / GBK / UTF-16 编码 |
| Outlook 邮件 | `.msg` `.oft` | 自动展开邮件里的 Excel / CSV 附件 |
| 标准邮件 | `.eml` | 同上，并支持正文中的 HTML 表格 |

不支持：`.xlsb`、加密的 Office 文件、`.pst` / `.ost` 邮箱数据库（见常见问题）。

### 5.2 字段映射

- 系统会按中英文同义词自动匹配表头，通常会直接匹配好。
- **表头不在第一行**：在映射页右上角「表头行」下拉里改选正确的行，映射会重新计算。
- **收入 / 支出分两列**：在「金额列」选择「收入金额 / 支出金额双列」，系统会自动拆成两笔记录，不需要再指定收支类型列。
- **整张表都是收入（或都是支出）**：在「收支类型」里选「整表收入 / 整表支出」。
- 同一个文件里的多个工作表可以分别勾选、分别映射。
- 成功导入一次后，相同表头的文件下次会自动套用上次的映射（可在设置里关闭）。

### 5.3 校验、异常与重复

校验结果分三类：

| 状态 | 含义 | 是否写入 |
|---|---|---|
| 正常 | 字段完整、格式正确 | 写入 |
| 有提示 | 可以导入，但有需要注意的地方（如缺类别、金额偏大） | 写入 |
| 异常 | 日期 / 金额 / 收支类型无法识别，或必填为空 | **不写入** |
| 疑似重复 | 与库内或本批次已有记录重复 | 按你选择的策略处理 |

- 点「下载校验明细」可以得到完整 CSV，在 Excel 里修正源文件后重新导入。
- 判断重复的规则：
  - **有单据编号**：年份 + 收支 + 单据编号 + 金额 + 类别
  - **无单据编号**：日期 + 收支 + 金额 + 类别 + 部门 + 往来单位 + 备注
- 重复处理策略：「跳过重复」或「更新已有记录」（更新会保留原记录 ID）。

### 5.4 数据明细（台账）

- 支持关键字搜索（类别、部门、往来单位、单据号、备注等）。
- 可按日期、收支、类别、部门、来源筛选，支持分页与排序。
- 可单条编辑 / 删除，也可勾选多条批量删除。
- 「导出」按钮可导出当前筛选结果为 **Excel**（含汇总页）或 **CSV**。

### 5.5 经营总览

- KPI：经营收入、经营支出、经营净额、流水笔数，均与上一周期对比。
- 期间切换：本月 / 本季 / 本年 / 全部 / 自定义。
- 近 12 个月收支趋势、收支构成、部门表现。
- 数据质量：分类完整度、未分类、未填部门、近期异常、重复识别。
- 点击类别或部门可直接下钻到筛选后的明细。

### 5.6 设置与数据安全

- 单位名称（显示在总览页顶部）、重复数据默认处理方式、是否记住字段映射。
- 查看数据目录、数据库大小、备份与临时文件占用。
- **立即备份**：把数据库下载到你指定的位置。
- **清理临时上传**：删除 24 小时前的导入暂存与过期报告。
- 字段映射习惯管理、最近操作记录、版本与离线升级。

## 六、数据、备份与迁移

### 6.1 数据放在哪里

| 运行方式 | 数据目录 |
|---|---|
| 便携运行 | 程序目录下的 `data\` |
| 安装到本机 | `%LOCALAPPDATA%\DataStatsWorkbench\data` |

目录结构：

```text
data\
├─ workbench.db       SQLite 主数据库（业务记录 / 批次 / 设置 / 审计）
├─ staging\           上传原文件与导入会话暂存（24 小时自动清理）
├─ reports\           批次异常明细 CSV
├─ backup\            每日自动备份 + 手动 / 升级前备份
├─ updates\           离线升级包暂存
└─ logs\              运行日志（workbench.log）
```

### 6.2 备份

- **自动**：每天首次启动保留一份 `workbench-daily-YYYYMMDD.db`，保留 14 份。
- **手动**：设置页「立即备份」，会下载一份数据库文件。
- 建议每周把备份复制到网盘或移动硬盘——备份放在同一块硬盘上，硬盘坏了等于没备份。

### 6.3 恢复

1. 退出工作台（设置与数据安全 → 退出工作台）。
2. 把备份文件复制为 `data\workbench.db`，覆盖原文件。
3. **删除**同目录下的 `workbench.db-wal` 与 `workbench.db-shm`。
4. 重新启动。

### 6.4 换电脑 / 迁移

把整个 `data` 文件夹复制到新电脑的对应位置即可，不需要导出再导入。
注意：`data` 里包含原始上传文件与备份，体积可能较大。

## 七、升级

1. 从 Release 页面下载新的升级包（`.zip` / `.hcup`），或新的完整包。
2. 打开「设置与数据安全 → 版本与离线升级」，选择升级包。
3. 本机会逐个文件校验 SHA-256，并把新版本放到独立的版本目录。
4. 按提示重启应用生效。
5. 旧版本会保留，可在「版本与离线升级」中切回；升级前的数据库会自动备份。

升级只替换程序文件，**不会改动 `data` 数据目录**。

> 如果你是从 v1.0.0 旧版本升级过来：v1.1.0 改了产品标识与数据库文件名，
> 旧升级包会被拒绝，请直接下载完整包并按第八节迁移数据。

## 八、从 v1.0.0 旧版本迁移

v1.1.0 把数据库文件名从 `hengce.db` 改成了 `workbench.db`，旧库不会被自动识别。
**不做这一步，旧数据等于丢失。**

**便携版**

1. 退出工作台；
2. 把旧目录 `data\hengce.db` 改名为 `data\workbench.db`；
3. 删除同目录的 `hengce.db-wal`、`hengce.db-shm`；
4. 用新版启动。

**安装版**

1. 备份旧目录 `%LOCALAPPDATA%\HengCeWorkbench\data`；
2. 把整个 `data` 复制到 `%LOCALAPPDATA%\DataStatsWorkbench\`；
3. 在其中把 `hengce.db` 改名为 `workbench.db`，删掉旧的 `-wal` / `-shm`；
4. 用新版 `Install-DataStats.cmd` 重装并启动，确认数据在；
5. 确认无误后，删除旧的 `%LOCALAPPDATA%\HengCeWorkbench` 与旧快捷方式。

## 九、常见问题

**Q1. 双击 `Start-DataStats.vbs` 没有任何反应？**
先运行 `Diagnostics.cmd`，它会检查运行时文件是否完整并显示缺失项。
再看 `data\logs\workbench.log` 末尾的报错。
最常见原因：没有完整解压，或只复制了压缩包里的部分文件。

**Q2. 浏览器没有自动打开？**
看启动窗口里提示的地址（形如 `http://127.0.0.1:8765`），手动粘贴到浏览器。
若浏览器提示端口被占用，程序会自动换到 8766、8767……以窗口提示为准。

**Q3. 关闭浏览器后程序还在运行吗？**
在。后台服务仍在监听本机端口。要彻底退出：设置与数据安全 → 底部「退出工作台」。

**Q4. 为什么同事的电脑打不开我的地址？**
设计如此。程序只监听 `127.0.0.1`，仅本机可访问，数据不出这台电脑。

**Q5. 邮件是 `.pst` / `.ost` 怎么办？**
这是 Outlook 的邮箱数据库格式，不直接解析。请在 Outlook 中把目标邮件另存为 `.msg`，或直接把附件拖进导入页。

**Q6. 表头识别错了行？**
在字段映射页右上角「表头行」下拉里选正确的行。合并单元格跨行表头建议先在 Excel 里整理。

**Q7. 提示「疑似重复」但我确实有两笔相同的？**
判重是保守的：宁可拦下也不重复入账。用修改单据编号或备注的方式区分这两笔，即可正常导入。

**Q8. 异常行很多，一条条改太麻烦？**
点「下载校验明细」，得到带行号与原因的 CSV，在 Excel 里批量修正源文件后重新导入。

**Q9. 导入很慢 / 页面卡住？**
单文件上限 80 MB、单次上传 240 MB、单表上限 50,000 行。超过请按年度或部门拆分。
超大文件建议先另存为 `.xlsx`（不要用 `.xls`）。

**Q10. 导出 Excel 时页面要等几秒？**
导出 5 万行约需 5–10 秒，属正常（写文件本身耗时）。期间请不要重复点击。

**Q11. 升级后打不开？**
运行 `Recovery-DataStats.cmd`，选择之前的版本恢复启动。数据目录不受影响。

**Q12. 数据会不会上传到网上？**
不会。所有解析都在本机进程内完成，代码中没有任何外部接口调用。可用断网环境验证。

**Q13. 杀毒软件报警？**
未签名的 `.vbs` / `.cmd` 启动脚本可能被启发式规则标记。这是无数字签名的常见误报，
可加入信任；介意的话用 `Start-DataStats-Console.cmd` 从命令行启动查看具体行为。

**Q14. 忘记备份，数据库坏了怎么办？**
先看 `data\backup\` 里的每日自动备份（保留 14 份），按 6.3 节恢复。
若数据库文件本身损坏，工作台启动时会做完整性检查并给出提示。

## 十、卸载

### 方式 A：便携版

1. 退出工作台（设置与数据安全 → 退出工作台）。
2. **先备份** `data\` 整个文件夹（如果还要这些数据）。
3. 直接删除整个程序文件夹即可。
   - 删除前请确认没有 `pythonw.exe` 在运行（任务管理器里搜 `pythonw`）。

### 方式 B：安装版

1. 退出工作台。
2. 删除桌面与开始菜单里的「数据统计工作台」快捷方式。
3. 删除 `%LOCALAPPDATA%\DataStatsWorkbench` 整个目录。
   - 该目录同时包含程序与数据。**若想保留数据，先把 `data` 复制出来。**
4. 完成。程序不写注册表，不装服务，不留后台进程。

> 卸载不会自动删除你的备份文件。如果曾把备份下载到桌面或文档目录，请自行清理。

## 十一、隐私与安全

- 全程离线：无 CDN、无外部字体、无云端接口，页面资源随程序分发。
- 仅监听 `127.0.0.1`，并对请求做 Host 与来源校验，拒绝跨站写入。
- 不写注册表、不安装系统服务、不需要管理员权限。
- 升级包在本机逐文件校验 SHA-256，但**未做数字签名**，请只使用本项目 Release 页面分发的包。

请像保管 Excel 台账一样保管 `data` 文件夹与数据库备份。
