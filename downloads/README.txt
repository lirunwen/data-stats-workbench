适用环境
------------------------------------------------------------
Windows 10 / 11 x64；无需安装 Python、Office、Node 或数据库；
目标电脑可以完全断网运行。

安装 / 启动
------------------------------------------------------------
1. 下载并完整解压 ZIP（不要直接在压缩包里双击）。
2. 便携运行：双击 Start-HengCe.vbs。
3. 安装到本机：双击 Install-HengCe.cmd（无需管理员权限）。
   程序会复制到 %LOCALAPPDATA%\HengCeWorkbench，并创建桌面快捷方式。
4. 数据默认位于 %LOCALAPPDATA%\HengCeWorkbench\data。
5. 需要停止后台服务：设置与数据安全 → 退出工作台。

升级恢复
------------------------------------------------------------
- 设置与数据安全 → 版本与离线升级，可选择升级包。
- 新版本无法启动时，运行 Recovery-HengCe.cmd 回退到旧版本。
- 详细说明见压缩包内 README.txt 和项目 README.md。

校验
------------------------------------------------------------
Windows 上可以使用 PowerShell 校验：
Get-FileHash .\HengCeWorkbench-Windows-x64-v1.0.0.zip -Algorithm SHA256

结果应与此文件第一行一致。
